# 🧠 LLMOps Gateway

A unified FastAPI gateway to interact with multiple LLM providers like **OpenAI** and **Ollama** using a single interface.

---

## 📦 Features

- ✅ Unified `/chat` endpoint
- 🤖 Supports:
  - OpenAI (GPT-3.5, GPT-4)
  - Ollama (local models like LLaMA 3, Mistral, etc.)
- 🔁 Easy to extend to other providers
- 🧪 Swagger UI at `/docs` for quick testing
- 🐳 Docker-ready (optional)
